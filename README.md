# iotdb时序库c++客户端库

这是一个用于 Apache IoTDB 时序数据库的 C++ 客户端库。

## 使用说明

1. 从 GitHub 克隆代码：

```bash
git clone https://github.com/<your-org>/libiotdb_session.git
cd libiotdb_session
```

2. 更新子模块：

```bash
git submodule update --init --recursive
```

3. 执行 build.sh 脚本编译：

```bash
bash build.sh
```

编译完成后，按项目说明使用生成的库和示例。
