# iotdb时序库c++客户端库

这是一个用于 Apache IoTDB 时序数据库的 C++ 客户端库。

## 使用说明

1. 从 GitHub 克隆代码：

```bash
git clone https://github.com/lehoon/libiotdb_session.git
```

2. 下载thrift库：

```bash
cd libiotdb_session
git clone https://github.com/apache/thrift.git
```

3. 执行 build.sh 脚本编译：

```bash
bash build.sh
```

编译完成后，按项目说明使用生成的库和示例。
